## 🎯 优化方向分析

### 1. 币种类型（BTC/ETH vs 山寨币）

#### 影响分析
- **BTC/ETH**: 波动性较小，流动性好，回调风险相对较低
- **山寨币**: 波动性大，流动性差，回调风险高

#### 优化建议
```go
// 山寨币使用更严格的阈值
if isBTCETH(symbol) {
    // BTC/ETH: 使用标准阈值
    baseThreshold = getTieredDrawdownThreshold(peakPct)
} else {
    // 山寨币: 收紧5-10%
    baseThreshold = getTieredDrawdownThreshold(peakPct) - 5.0
}
```

#### 预期效果
- 山寨币回撤阈值从30%降至25%，更早保护
- BTC/ETH保持30%，避免过早平仓

#### 数据支持
- 历史数据：所有15次回撤触发都是山寨币
- 说明：山寨币确实需要更严格的保护

---

### 2. 使用杠杆

#### 影响分析
- **高杠杆**（≥10x）: 风险放大，应该用更严格的阈值
- **低杠杆**（<5x）: 风险较小，可以使用标准阈值

#### 优化建议
```go
// 根据杠杆调整阈值
leverageAdjustment := 0.0
if leverage >= 15 {
    leverageAdjustment = -5.0  // 高杠杆：收紧5%
} else if leverage >= 10 {
    leverageAdjustment = -3.0  // 中等杠杆：收紧3%
} else if leverage >= 5 {
    leverageAdjustment = 0.0   // 标准杠杆：不调整
} else {
    leverageAdjustment = 2.0   // 低杠杆：放宽2%（让利润奔跑）
}
```

#### 预期效果
- 15x杠杆：阈值从30%降至25%
- 10x杠杆：阈值从30%降至27%
- 5x杠杆：保持30%
- <5x杠杆：阈值从30%放宽至32%

#### 理论依据
- 杠杆越高，价格波动对盈亏的影响越大
- 高杠杆下，小幅回调可能导致大幅亏损
- 应该用更严格的阈值保护

---

### 3. 入场价格（相对位置）

#### 影响分析
- **历史高位入场**: 回调风险高，应该用更严格的阈值
- **历史低位入场**: 回调风险低，可以使用标准阈值

#### 实现复杂度
⚠️ **较高**
- 需要获取历史K线数据
- 需要计算价格分位数
- 可能影响性能

### 4. 近期趋势

#### 影响分析
- **上升趋势**: 回调可能是正常调整，可以放宽阈值
- **下降趋势**: 回调可能是趋势反转，应该收紧阈值
- **震荡**: 使用标准阈值

#### 实现方式
- 分析最近K线的EMA趋势
- 或使用已有的市场数据（如果回撤监控可以访问）

#### 优化建议
```go
// 获取近期趋势（需要市场数据）

// trend: "uptrend", "downtrend", "sideways"

case "uptrend":
    trendAdjustment = 2.0  // 上升趋势：放宽2%（让利润奔跑）
case "downtrend":
    trendAdjustment = -5.0 // 下降趋势：收紧5%（及时止损）
case "sideways":
    trendAdjustment = 0.0  // 震荡：不调整
}
```

#### 评估
⚠️ **需要获取市场数据，可能影响性能，建议作为可选优化**

**理由**:
- 需要调用市场数据API（可能已有缓存）
- 需要分析K线数据计算趋势
- 可能影响回撤监控的性能（需要异步或缓存）

## 💡 推荐优化方案

### 方案A：基础优化（推荐，立即实施）

#### 考虑因素
1. ✅ **币种类型**（BTC/ETH vs 山寨币）
2. ✅ **使用杠杆**

#### 优点
- ✅ 实现简单，风险低
- ✅ 数据易获取（已有symbol和leverage）
- ✅ 效果明显
- ✅ 不影响性能（无需额外API调用）

#### 实现代码
```go
// getTieredDrawdownThreshold returns drawdown threshold based on profit level and risk factors
func getTieredDrawdownThreshold(peakPct float64, symbol string, leverage int) float64 {
    // 基础阈值（基于峰值利润）
    baseThreshold := 0.0
    if peakPct >= 25.0 {
        baseThreshold = 30.0
    } else if peakPct >= 12.0 {
        baseThreshold = 30.0
    } else if peakPct >= 6.0 {
        baseThreshold = 25.0
    } else {
        return 0.0
    }

    // 币种类型调整：山寨币波动性大，使用更严格的阈值
    if !isBTCETH(symbol) {
        baseThreshold -= 5.0  // 山寨币：收紧5%
    }

    // 杠杆调整：杠杆越高，风险越大，使用更严格的阈值
    if leverage >= 15 {
        baseThreshold -= 5.0  // 高杠杆（≥15x）：收紧5%
    } else if leverage >= 10 {
        baseThreshold -= 3.0  // 中等杠杆（10-15x）：收紧3%
    } else if leverage < 5 {
        baseThreshold += 2.0  // 低杠杆（<5x）：放宽2%
    }

    // 确保阈值在合理范围（15%-40%）
    if baseThreshold < 15.0 {
        baseThreshold = 15.0  // 最低15%（避免过于敏感）
    }
    if baseThreshold > 40.0 {
        baseThreshold = 40.0  // 最高40%（避免过于宽松）
    }

    return baseThreshold
}
```

#### 调用方式
```go
// 在 checkPositionDrawdown 中
drawdownThreshold := getTieredDrawdownThreshold(peakPnLPct, symbol, leverage)

// 在验证阶段
realDrawdownThreshold := getTieredDrawdownThreshold(refreshPeakPnlPct, symbol, refreshLeverage)
```

#### 预期效果
- **山寨币+10x杠杆**：阈值从30%降至22%（更早保护）
- **BTC/ETH+5x杠杆**：保持30%（标准保护）
- **预期减少高回撤**（≥60%）从20%降至10%以下
